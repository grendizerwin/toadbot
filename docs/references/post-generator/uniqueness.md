# Anti-generic engine

If a draft could be posted for any other memecoin by swapping the ticker, it is a fail. Rewrite.

## Banned recycled lines (do not use unless quoting someone else)

- "The first Pepe was a toad. 1988."
- "Frog came second."
- "The toad never left the pond."
- "Toad army still croaking."
- "Quietly one of the most memeable characters on Solana."
- "Most memes die after the first dump. $TOAD is still here."
- "Who else bought the original Pepe thesis?"
- "toad mode activated"
- "Still early in the pond."
- "The show will go on"
- "Who's still holding the original?"
- Any sentence that is only "original Pepe since 1988" with no new detail

Lore is background, not the daily hook. Use 1988 / original-Pepe framing at most once every several runs, and only if research gives a new reason.

## Every option must pass this checklist

1. **Anchor lock.** The post is anchored to one real thing: either a concrete item from the last 24–48h research (a specific official caption or visual, a site update, a community reply worth reacting to), **or** today's real calendar moment (the actual weekday, time of day, weekend, holiday, season). Both batch 001 winners were calendar-anchored everyday moments. No invented catalysts, no market numbers in captions.
2. **Hook-class lock.** Name the class in the package. The two options must use two different classes.
3. **Continuity lock.** After reading `from:<owner_handle>` latest 5–8 posts, do not repeat the same joke, the same structure, or the same first line. If yesterday was lore, today is not lore.
4. **Voice lock.** Sound like a pond member living an everyday moment, not a brand intern, a thesis account, or the project. Official @thetoadmeme_ is ultra-dry and image-first. User captions stay in that neighborhood: one beat, maybe two. Load `caption-voice.md`. Not a thread-shaped essay. Not "TOAD deserves a holder like you."
5. **Swap test.** Replace $TOAD with $RANDOM and the plush with a random frog. If the post still works, kill it. Brand vocabulary (the pond, tomorrow problem, having a day) plus the plush in the scene pass.
6. **De-AI pass.** After both options exist, run sibling `avoid-ai-writing` internally. Slogan cadence, inflated "quietly one of the most" lines, chatbot closers, and em-dash stacking are fails even if the swap-test passes.
7. **Situation lock.** The first line names a concrete moment or object (see `viral-hooks.md`). Toad's face never changes, so the situation carries the joke.
8. **Safety lock.** No price, pump, promise, or advice. No CA unless asked. No official-announcement framing. Never mean.

## Hook classes (pick 2 different ones per run)

Situation-first patterns are in `viral-hooks.md` (line → prop, quote + time-skip, tiny promise vs reality, tomorrow-problem handoff, calendar collision, status label, small honest count, warm invite). Other classes:

- QT / reply to a specific official post (best when official media is strong)
- Caption the official visual gag in one dry line
- Specific community moment (a reply, art, game score), only if real
- Object-level joke about today's official photo
- Holder-diary beat that continues the last post without repeating it
- Argentine / song / childhood angle only when a real cultural beat is in the news that day

Dropped: market-color hooks. Numbers about price or MC never go in captions.

## Diversity requirements

- Option 1 and Option 2 cannot share the same first four words.
- Do not start two runs in a row with "Good morning" / "Gtoad" / "It's time" unless quoting official.
- Prefer quote-tweeting official media over generating a new image when the official visual is already the joke.
- If generating/editing an image, the scene must be new versus the last generated scene you can see in continuity notes.
- Max one 🐸 per post.
- Endings: at most half the captions in a batch end in `🐸 $TOAD`. $TOAD can sit mid-line or be left out.
- At most one weekday joke (monday, tuesday, sunday night) per batch; Oct 18–20 ran nine and reach fell each day.
- Hashtags: none by default.
