# Adjacent surfaces — when a TOAD reply belongs

A reply popularizes $TOAD only if a stranger reading the parent already has a reason to care about *this* character. If you have to invent the bridge, the thread is not adjacent.

## Pass — TOAD already in the room

- Parent names $TOAD, El Toad Pepe, El Sapo Pepe, the official plush, or @thetoadmeme_
- Someone asks what the token / character is
- A human quote-tweeted official media
- A real product beat is live (game, site, clip, listing) and a person is talking about it

Action: amplify with a new beat. Do not repeat "🐸 $TOAD" under official.

## Pass — adjacent enough for a soft shill

The parent is about one of these *and* you can add a specific observed detail:

- Frog vs toad / "original Pepe" chronology talk (do not claim theft; chronology joke only if it is new today)
- Argentine or LatAm childhood / kids-TV / song memory that actually names a toad or Pepe
- Mascot / plush / brand-not-chart arguments ("this coin has a face")
- Culture-coin posts where a live official visual or game is the add
- Someone posting a green frog and getting the character wrong (kindly correct with the official plush look, not a lecture)
- Everyday-moment posts (monday, one more meeting, sunday night, weekend) **only** when the author is already in or near the pond; for strangers, the reply must work without the ticker

The reply should still make sense if the reader never clicks your profile.

## Fail — not adjacent

- Random Solana / BNB / Robinhood runner with no character overlap
- Pure price-spam, chart-only dumps, "100x" calls
- BTC / ETH macro, politics, sports, unrelated AI art
- Another project's mascot unless the parent is comparing faces
- Launchpad factory cards
- Threads where the only add is "we have a toad too"
- Trolls, scams, copycat contracts, FUD fights (skip, don't argue)

Skip those.

## Official threads are special

Replying under @thetoadmeme_ is usually low leverage (their own community is already there) unless:

- The comment section is still small and you can poke a *detail in today's photo/clip*
- A confused outsider asked a real question
- You are quote-replying a *person* who QTed official, not stacking under official

Default: prefer the human QT over the official parent.

## Image-adjacent vs text-adjacent

Use an official-plush image only when:

- The parent is already visual (photo, clip, mascot debate, "what frog is this")
- The joke is the face / outfit / scene, not the ticker
- Official did not already post that scene today

Use text when the parent is a question, a number, or an argument. Attaching the plush to a chart dump looks like a raid.
